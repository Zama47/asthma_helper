## Полное описание

```
Asthma Helper — дневник для людей с бронхиальной астмой: пикфлоуметрия, лекарства, приступы и условия среды в одном приложении. Помогает видеть динамику и приходить на приём к врачу с понятной картиной, а не с обрывками воспоминаний.

ЧТО УМЕЕТ
• Пикфлоуметрия (ПСВ): замеры с оценкой по личной норме и цветовым зонам (зелёная, жёлтая, красная).
• Графики и статистика: динамика ПСВ, средние значения, лучший результат, число дней с измерениями.
• Лекарства: расписание приёмов, отметки о приёме, напоминания.
• Приступы: журнал приступов, счётчик доз неотложной помощи, предупреждение о затянувшемся ухудшении.
• Тест контроля астмы (ACT): 5 вопросов, итоговый балл от 5 до 25 и его трактовка.
• Календарь: все события по дням.
• Погода и воздух: температура, влажность, давление, ветер, индекс качества воздуха (AQI), концентрации PM2.5, PM10, O₃, NO₂, уровень пыльцы.
• Виджет на рабочем столе: три кнопки — «приступ», «замер ПСВ», «лекарства приняты».
• Экспорт: выгрузка замеров в CSV (включая суточные сводки) и отправка файла любым удобным способом.

ДЛЯ КОГО
Для взрослых и подростков, которые измеряют ПСВ дома и хотят вести дневник аккуратно, без бумажных таблиц.

ВАЖНО
Приложение носит информационно-справочный характер, не является медицинским изделием, не ставит диагноз и не заменяет консультацию врача. Решения о лечении принимайте вместе со специалистом. При тяжёлом приступе вызывайте скорую помощь.

КОНФИДЕНЦИАЛЬНОСТЬ
Медицинские записи хранятся только на вашем устройстве и не передаются разработчику или третьим лицам. Разрешение на геолокацию используется исключительно для определения города при загрузке прогноза, город можно выбрать вручную. Рекламы и трекеров в приложении нет.
```

## Обоснование разрешений (для модерации)

| Разрешение | Зачем нужно |
| --- | --- |
| `INTERNET` | Загрузка прогноза погоды, качества воздуха и уровня пыльцы (Open-Meteo). Основной функционал работает без интернета. |
| `ACCESS_COARSE_LOCATION`, `ACCESS_FINE_LOCATION` | Определение города для прогноза. Разрешение необязательное: при отказе город выбирается вручную из списка. |
| `POST_NOTIFICATIONS` | Напоминания о приёме лекарств и о замере ПСВ. Пользователь может отключить их в настройках системы. |

Дополнительно: приложение не запрашивает доступ к контактам, камере, микрофону, файлам и телефону. Аналитики, рекламных SDK и трекеров нет. Экспорт CSV использует `FileProvider` и системный диалог «Поделиться» — разрешения на хранилище не требуются.

Почему скриншоты именно такие: из исходных снимков убраны системные панели (статусбар сверху,
панель навигации снизу) — RuStore не принимает скриншоты с элементами системы. Снимок домашнего
экрана с виджетом в витрину не берётся: там видны чужие приложения (звонки, сообщения, камера),
а чужие бренды в скриншотах — риск на модерации. При желании витрину можно дополнить снимком
самого виджета, вырезанным по его границам.
