# Asthma Helper

Android-приложение для отслеживания пикфлоуметрии, приёма лекарств, погоды и качества воздуха (AQI).

## Технологии
- Kotlin, Jetpack Compose
- MVVM + Clean Architecture
- Hilt, Room, Retrofit
- Open-Meteo API (погода + AQI + пыльца)

## Функции
- 🫁 Трекер пикфлоуметрии с графиками
- 💊 Расписание приёма лекарств
- 🌤️ Погода и качество воздуха (AQI)
- 🌿 Уровень аллергенности (реальная пыльца)

## Стек
- AGP 9.1.1, Kotlin 2.2.0, Compose BOM 2024.09
- Room 2.8.4, Hilt 2.60.1, Vico 2.1.2
