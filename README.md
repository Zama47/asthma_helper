# 🫁 Asthma Helper

Android-приложение для людей с астмой: трекер пикфлоуметрии, расписание приёма лекарств с напоминаниями, погода и качество воздуха.

## ✨ Функции

### 📊 Главная
- Быстрое добавление замера пикфлоуметрии
- Виджеты уровня аллергенности и качества воздуха (реальные данные из API)
- Чек-лист приёмов лекарств на сегодня с независимыми отметками
- Сводка: последний замер + норма, история записей с цветными индикаторами

### 🫁 Дыхание
- График динамики пикфлоуметрии (Vico Charts)
- **Три зоны нормы** (классическая пикфлоуметрия):
  - 🟢 Зелёная: 80–100% от максимума — всё хорошо
  - 🟡 Жёлтая: 50–80% — внимание
  - 🔴 Красная: < 50% — срочно к врачу
- Добавление замера **на произвольную дату и время** (TimePicker)
- Фильтр по периоду: день / неделя / месяц / год
- Настройка нормы: вручную или по формуле (возраст + рост)

### 💊 Лекарства
- Расписание приёмов: время, дозировка, **дни недели**
- Выбор лекарства из **16 предзаполненных популярных** (Сальбутамол, Будесонид, Серетид...) или создание нового
- Уведомления-напоминания через WorkManager (проверка расписаний каждые 15 минут)

### 🌤️ Погода
- Текущая погода: температура, ощущается как, влажность, давление, ветер
- Качество воздуха: **европейский AQI (0–100+)**, PM2.5, PM10, O₃, NO₂
- **Реальная пыльца** из Open-Meteo: берёза, ольха, злаки, полынь, амброзия
- Персональные рекомендации на основе AQI, пыльцы и ветра
- Геолокация устройства (FusedLocationProvider) + обратное геокодирование названия города

## 🛠 Технологии

| Слой | Технологии |
|---|---|
| Язык | Kotlin 2.2.0 |
| UI | Jetpack Compose, Material 3 |
| Архитектура | MVVM + Clean Architecture (data / domain / ui) |
| DI | Hilt 2.60.1 |
| БД | Room 2.8.4 (5 сущностей, Flow-реактивность) |
| Сеть | Retrofit 2.11 + OkHttp |
| Графики | Vico 2.1.2 |
| Фон | WorkManager + HiltWorker |
| Геолокация | Google Play Services Location |
| Сборка | AGP 9.1.1, KSP, compileSdk 37, minSdk 24 |

## 🌐 Внешние API (все бесплатные, без ключей)

- [Open-Meteo Forecast](https://open-meteo.com/en/docs) — погода
- [Open-Meteo Air Quality](https://open-meteo.com/en/docs/air-quality-api) — AQI + пыльца
- [BigDataCloud](https://www.bigdatacloud.com/) — обратное геокодирование (название города)

## 🏗 Структура проекта

```
app/src/main/java/com/example/asthmahelper/
├── data/            # Реализация: Room, Retrofit, репозитории
├── domain/          # Бизнес-логика: модели, интерфейсы, use cases
├── di/              # Hilt-модули
├── notification/    # WorkManager-воркер напоминаний
├── util/            # Провайдер геолокации
└── ui/              # Compose-экраны + ViewModel'ы
    ├── dashboard/   # 📊 Главная
    ├── breathing/   # 🫁 Дыхание
    ├── medications/ # 💊 Лекарства
    └── weather/     # 🌤️ Погода
```

Поток данных: `UI → ViewModel → UseCase → Repository → DAO/API`  
Реактивность: `Flow → StateFlow → collectAsState()`

## 🚀 Запуск

1. Клонируй репозиторий:
```bash
git clone https://github.com/Zama47/asthma_helper.git
```
2. Открой в Android Studio (Ladybug или новее)
3. Sync Gradle и запусти на устройстве/эмуляторе (Android 7.0+)

API-ключи не требуются — все внешние сервисы бесплатные и работают без регистрации.
